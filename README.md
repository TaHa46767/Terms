# Terms
​ملكية المحتوى وحقوقه: "أنت تحتفظ بجميع حقوق الملكية الفكرية للمحتوى الذي تنشئه أو ترفعه." تمنحنا فقط ترخيصاً محدداً للحد الأدنى اللازم لتشغيل الخدمة وعرض محتواك داخل المنصة.
​حرية الاستخدام والتحكم: "لك كامل الحرية في تخصيص حسابك، تصدير بياناتك، أو تعديل طريقة استخدامك للخدمة." لا نلزمك بأي أنماط استخدام محددة طالما أنها لا تتسبب في ضرر للآخرين.
​إلغاء الحساب وتصدير البيانات: "يمكنك مغادرة المنصة وحذف حسابك في أي وقت دون أي قيود أو رسوم إلغاء." نتيح لك خيار تحميل كافة بياناتك ومشاريعك بنقرة واحدة قبل المغادرة.
​الحد الأدنى من القيود: "القاعدة الأساسية هي الامتناع عن السلوكيات التي تضر بالبنية التحتية أو تنتهك حقوق باقي المستخدمين." عدا ذلك، الميزات والأدوات متاحة لك لتستخدمها بالطريقة التي تناسب احتياجاتك.
​مرونة التحديثات: "إذا قمنا بتحديث هذه الشروط، سنخطرك بمهلة زمنية كافية." إذا كانت التغييرات لا تناسبك، يحق لك الاستمرار بالنسخة الحالية أو إنهاء حسابك بسلاسة.
